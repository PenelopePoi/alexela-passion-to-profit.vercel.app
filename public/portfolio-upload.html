Move your project photos from Drive into the designated portfolio folder.

Upload from Google Drive

  1. Open the upload folder using the button below.
  2. In Drive, select existing photos → Organize → Move → choose “AleXelA Portfolio — Upload Before and After Photos.” For new files, use + New → File upload.
  3. Keep original resolution. Name photos by project and category: Logos, Business Cards, Flyers, Door Hangers, Shirts & Apparel, Merchandise, Stickers & Decals, BMX Decal Sets or Motorcycle Decal Sets. Before-and-after pairs are optional.
  4. Add a short note with the project name, what you created and which photos you want published.
Open portfolio upload folder ↗

Google account access is required. Files placed here remain in Drive; they are not automatically published to the website. Publication requires adding selected artwork to the portfolio.
