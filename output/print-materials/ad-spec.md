## Canva Build Instructions (All Variants)

### Setup
1. Open Canva > Create Design
2. For feed posts: **Instagram Post (Square)** — 1080 x 1080
3. For stories: **Instagram Story** — 1080 x 1920

### Building Each Variant

#### Portfolio Showcase
1. Use a split background (two rectangles stacked)
2. For mockups: search Canva for "brand identity mockup" or "business card mockup" — use a smartmockup or upload your own portfolio images
3. Apply drop shadow to mockup group via Canva's shadow effect

#### Price Anchor
1. Make the "$75" text very large (use Canva's max text size, then resize the text box)
2. For the teal glow: place a blurred teal circle (use Canva's blur effect on a #00E0C6 circle, ~30% opacity) behind the price text
3. CTA pill: rounded rectangle + text grouped together

#### Before/After
1. For the split layout: two rectangles side by side (feed) or stacked (story)
2. Before mockups: deliberately use Canva's less polished templates or create an "ugly" brand on purpose — mismatched fonts, generic clipart, bad spacing
3. After mockups: use your best portfolio work or Canva's premium mockup templates
4. Add the arrow/transition element at the split point

### Export
- **For paid ads:** PNG, highest quality
- **For organic posts:** JPG is fine, high quality
- Dimensions will auto-match the template

## Facebook/Instagram Ad Campaign Settings

| Setting | Recommendation |
|---------|---------------|
| Campaign Objective | Leads or Messages |
| Audience | 25-55, Brevard County FL + 25mi radius |
| Interests | Small business, entrepreneurship, marketing |
| Placement | Instagram Feed, Instagram Stories, Facebook Feed, Facebook Stories |
| Budget | $5-15/day per variant for testing |
| Run Duration | 7 days per A/B test cycle |
| CTA Button | "Call Now" or "Book Now" or "Learn More" |

### A/B Testing Plan
1. **Week 1:** Run all 3 variants with identical audiences ($5/day each)
2. **Week 2:** Kill the lowest performer, increase budget on top 2
3. **Week 3:** Scale the winner to $15-20/day, test new copy variations
4. Track: Cost per lead, click-through rate, phone calls received
