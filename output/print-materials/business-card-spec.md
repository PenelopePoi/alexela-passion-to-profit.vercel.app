# XELA Creative Branding Studio — Business Card Design Spec

## Document Setup

| Property | Value |
|----------|-------|
| Finished Size | 3.5" x 2" (standard US business card) |
| With Bleed | 3.75" x 2.25" (0.125" bleed on all sides) |
| Safe Zone | 3.25" x 1.75" (0.125" margin inside trim) |
| Resolution | 300 DPI minimum |
| Color Mode | CMYK |
| File Format | PDF/X-1a for print, PNG for digital preview |

---

## FRONT SIDE

### Background
- Solid fill: **#F5F2ED** (warm brand paper/cream)

### Layout (Left-Aligned Composition)

#### XELA Logo
- Position: Top-left, 0.25" from safe zone edges
- Size: ~1.4" wide
- Use primary logo lockup (wordmark + icon)
- Color: **#111111** (brand black)

#### Name & Title Block
- Position: Below logo, 0.15" gap
- **Name:** `[First Last]`
  - Font: **Cormorant Garamond Bold**, 11pt
  - Color: **#111111**
- **Title:** `Creative Director` (or relevant title)
  - Font: **Cormorant Garamond Italic**, 8pt
  - Color: **#333333**

#### Tagline
- Position: Bottom-left, 0.25" from bottom safe edge
- Text: **"Your Marketing Team"**
- Font: **Outfit Medium**, 7pt
- Color: **#00E0C6** (brand teal)

#### Accent Element
- Thin horizontal rule: 1pt line, **#00E0C6**, spanning ~1.5" below the title block
- Optional: small teal dot or diamond separator before tagline

## Canva Build Instructions

1. **Open Canva** > Create Design > Search "Business Card" (3.5 x 2 in)
2. **Page 1 = Front:**
   - Set background to #F5F2ED
   - Upload XELA logo (SVG or high-res PNG), place top-left
   - Add text elements for name, title, tagline per spec above
   - Draw a thin line element, color #00E0C6
3. **Page 2 = Back:**
   - Set background to #111111
   - Upload XELA icon mark, place top-center
   - Add centered text stack for contact info (use separate text boxes for color control)
   - Generate QR code: use Canva's built-in QR code app (Apps > QR Code) — link to booking URL
   - Place QR bottom-right, resize to ~0.55"
   - Add "Digital. Print. Everything." tagline
4. **Export:** PDF Print (with bleed and crop marks enabled)

## Vistaprint Instructions

1. Choose **Standard Business Card, 3.5 x 2"**
2. Select **Matte or Soft-Touch Matte** finish (matches brand aesthetic)
3. Upload front/back as separate PDF files or use their editor
4. Paper stock: **16pt Premium Matte** or **Signature Soft Touch**
5. Ensure bleed extends to edges — Vistaprint will show trim warnings if not

## Print-Ready Checklist

- [ ] All text within safe zone (0.125" inside trim)
- [ ] Background colors extend to bleed edge
- [ ] Fonts outlined/embedded in PDF
- [ ] QR code scans correctly at printed size
- [ ] CMYK color mode (not RGB)
- [ ] 300 DPI minimum resolution
- [ ] Proof printed at actual size to verify readability
