## Canva Build Instructions

1. **Open Canva** > Create Design > Custom Size: **3.5 x 8.5 inches**
2. **Page 1 = Front:**
   - Set background to #111111
   - Add a white circle (1.5" diameter) centered at top — this marks the die-cut hole area. Add a note "DIE CUT — DO NOT PRINT" on the circle
   - Build layout top-to-bottom per spec
   - For the price anchor: use a rounded rectangle element, fill #00E0C6
   - QR code: Apps > QR Code > enter booking URL
3. **Page 2 = Back:**
   - Set background to #F5F2ED
   - Same hole marker at top
   - Build the checklist using text elements with checkbox icons from Canva's icon library
   - Bottom bar: dark rectangle spanning width
4. **Export:** PDF Print (with crop marks and bleed)
5. **Note to printer on export:** Include die-cut template or dieline for the door handle hole

## Print Specs for Printer

| Property | Value |
|----------|-------|
| Size | 3.5" x 8.5" |
| Stock | 14pt C2S (coated two sides) or 16pt cover |
| Sides | 2 (front and back) |
| Coating | UV Gloss front, Matte back (or AQ both sides) |
| Die-Cut | 1.5" diameter circle hole, centered horizontally, center point 1.25" from top edge |
| Quantity | 250-500 typical run |

**Dieline notes:** Provide a separate dieline layer (usually magenta or spot color) showing the circle cutout. Most door hanger printers have a standard template — request theirs and match the hole position.
