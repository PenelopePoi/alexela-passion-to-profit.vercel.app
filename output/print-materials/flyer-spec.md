## Canva Build Instructions

1. **Open Canva** > Create Design > Custom Size: 8.5 x 11 inches
2. **Build section by section** from top to bottom:
   - Use rectangles for background sections (extend to edges for bleed)
   - Use Canva's grid/columns feature for the 3 service blocks
   - For trust bar: dark rectangle with 3 evenly-spaced icon+text combos
3. **Tear-off tabs:**
   - Create a table or grid at the bottom (10 columns, 1 row)
   - Add dashed line using Canva's line tool (set to dashed style)
   - Rotate text 90 degrees within each cell
4. **QR Code:** Apps > QR Code > paste booking URL
5. **Icons:** Use Canva's built-in icon library — search "shield", "lightning", "rocket"
6. **Export:**
   - For print: PDF Print (select "Crop marks and bleed")
   - For digital distribution: PNG, high quality
